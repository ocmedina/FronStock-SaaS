# Exports

Esta carpeta contiene bundles de datos para la importacion legacy.

Los archivos pueden incluir informacion de clientes, ventas, pagos, proveedores y perfiles. No agregues datos de produccion al repositorio. Conserva los bundles reales en almacenamiento privado y utiliza esta carpeta solo para ejemplos o archivos temporales locales.

La estructura y el proceso de importacion estan documentados en [docs/legacy-import.md](../docs/legacy-import.md).
